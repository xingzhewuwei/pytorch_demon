# 阶段 3 · 多变量线性回归（房价预测）

## 目标

把阶段 1-2 串成一个**完整的监督学习闭环**，并亲手踩两个经典坑、学会正确修法。
这一节的直接产物就是仓库根目录的 `main.py`。

## 场景

用 3 个特征预测房价：房屋面积、房间数量、距离地铁距离。
真实规律：`房价 = 0.5*面积 + 2.0*房间数 - 1.5*地铁距离 + 10`

## 这个脚本在演示什么

1. 造数据：标签 **用原始特征** 生成，X 再单独归一化
2. 标签 y **也标准化**（关键！否则 2000 步都训不收敛）
3. 前向 `X @ w + b`、MSE 损失、Adam 优化、学习率指数衰减、早停（Early Stopping）
4. 反归一化：把学到的系数还原回真实世界尺度
5. 可视化：预测 vs 真实 的散点 / 柱状 / 折线三图

## 怎么跑

```bash
uv run main.py                 # 或 uv run lessons/03_regression.py（内容一致）
```

输出示例（收敛后）：

```text
机器学到: y = 0.493*面积 + 2.070*房间数 + (-1.526)*地铁距离 + 10.93
真实规律: y = 0.500*面积 + 2.000*房间数 + (-1.500)*地铁距离 + 10
预测: 真实 79.66 → 机器 80.79 | 真实 84.45 → 86.56 | 真实 54.98 → 53.64
```

并保存 `house_price_v2.png`。

## 两个核心坑（务必理解）

- **坑 1**：标签用「归一化后的 X」生成 → 面积这种弱信号被噪声淹没，系数学成 0。
  ✅ 修法：标签必须用**原始特征**生成，归一化只作用于模型输入 X。
- **坑 2**：只标准化 X、y 没标准化 → y 均值 ~62，Adam 有效步长 ≈ `lr`，截距要 6000+ 步才爬到位，2000 步根本没收敛（loss 停在 3100）。
  ✅ 修法：**标签 y 也标准化**（`(y - y_mean) / y_std`）。

## 过关自测

- 跑通后学出的系数接近真实规律（面积≈0.5、房间≈2.0、地铁≈-1.5、截距≈10）
- 能向别人解释「为什么标签也要标准化」

## 一句话总结

监督学习闭环 = 造数据 → 输入/标签双标准化 → 建参数 → 前向 → 算 loss → 反向 → 优化器更新 → 早停 → 反归一化验证。
