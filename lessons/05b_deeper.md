# 阶段 5b：分类任务 · 加深对照版

> 对应脚本：`lessons/05b_deeper.py`
> 运行：`uv run lessons/05b_deeper.py`
> 前置：先读完 `05_classification.md`，本篇是「加层」的实战演练。

## 目标

阶段 5 你已经跑通了**单层**分类网络 `2→16→3`（99 参数）。这节把它加深成 **3 个隐藏层**：

```
输入(2) → 64 → 32 → 16 → 输出(3)
```

目标不是「准确率更高」（玩具数据单层已经 100%），而是**亲手掌握深度学习里「深」字的本意**：

> 加层数 = 增加模型的表达能力，能拟合更复杂的边界 / 函数。

## 1. 唯一的硬规则：维度链要对上

每一层 `Linear(in, out)` 的 `in` 必须等于上一层的 `out`：

```python
self.net = nn.Sequential(
    nn.Linear(2, 64),     # in=2
    nn.ReLU(),
    nn.Linear(64, 32),    # in=64 == 上一层 out=64 ✅
    nn.ReLU(),
    nn.Linear(32, 16),    # in=32 == 上一层 out=32 ✅
    nn.ReLU(),
    nn.Linear(16, 3),     # in=16 == 上一层 out=16 ✅，输出=类别数
)
```

断链（比如上一层出 64、下一层进 32，中间没接上）会直接报形状错。**盯着这条数字链就不会错。**

> 提示：脚本里为了简洁用了 `n_hidden` 参数化写法（`n_hidden*4 / n_hidden*2 / n_hidden`），
> 默认 `n_hidden=16` 时正好展开成上面的 `2→64→32→16→3`。两种写法等价，看懂一个即可。

## 2. 参数量怎么算（动手必会）

`Linear(in, out)` 的参数 = `in × out`（权重）+ `out`（偏置）。逐层累加：

| 层 | 权重 W | 偏置 b | 合计 |
|---|---|---|---|
| `Linear(2,64)` | 2×64=128 | 64 | 192 |
| `Linear(64,32)` | 64×32=2048 | 32 | 2080 |
| `Linear(32,16)` | 32×16=512 | 16 | 528 |
| `Linear(16,3)` | 16×3=48 | 3 | 51 |
| **总计** | | | **2851** |

对比单层基线 `2→16→3`：`(2×16+16)+(16×3+3) = 48+51 = 99` 参数。

**加深版参数 ≈ 单层的 28 倍。**

## 3. 运行预期

```
ToyClassifier(
  (net): Sequential(
    (0): Linear(in_features=2, out_features=64, bias=True)
    (1): ReLU()
    (2): Linear(in_features=64, out_features=32, bias=True)
    (3): ReLU()
    (4): Linear(in_features=32, out_features=16, bias=True)
    (5): ReLU()
    (6): Linear(in_features=16, out_features=3, bias=True)
  )
)
...
✅ 训练集准确率: 100.00%
📊 已保存 classification_result.png
```

准确率和单层版一样是 100% —— 因为玩具数据太简单，**浅网络已经是「容量过剩」**。

## 4. 重点理解：不是越深越好

这是加深实验最该记住的反直觉点：

- **参数多了 28 倍，准确率没从 100% 变 101%**，因为它本来就是 100%。
- 真实数据上，**过度加深会带来两个问题**：
  - **过拟合**：参数远多于数据里的「有效信息」，模型开始背答案而非学规律；
  - **梯度消失 / 训练变慢**：层越多，反向传播时梯度越传越小，深层难训。
- 所以工程上「深度 / 宽度要匹配数据复杂度」，而不是无脑堆层。
