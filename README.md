#### 继续优化 特征归一化

🛠️ 怎么修？（工业界标准做法：特征归一化）
在把数据喂给机器之前，我们需要把所有特征“拉平”到同一个起跑线上（比如都缩放到 0~1 之间）。这在深度学习中叫做 特征归一化（Normalization）
